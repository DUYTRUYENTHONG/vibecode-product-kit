# Delivery handoff

Identify the exact task, branch, candidate and current owner. Inspect the current working tree before trusting an old summary. Preserve concurrent edits.

Record last completed action, files/contracts affected, tests actually run, evidence, next executable action and unresolved approvals. A blocker needs reason, owner and required external change. Distinguish a code failure from missing credentials/infrastructure before any retry.

Resume the selected workstream rather than opening a duplicate agent/chat. Continue independent safe work where possible; do not create an automatic restart loop. Model routing stays with the caller's approved risk policy.

Keep implemented, QA verified, preview approved and production verified separate. A resume note never grants new permissions or proves a deployment.
