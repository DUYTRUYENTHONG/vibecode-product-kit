# Roadmap and current status

## Implemented in 0.1.0
- Offline initialization with dry-run default and overwrite refusal.
- Feature/dependency/evidence record validation and status reporting.
- Review-only Jira export with stable requirement/issue mapping.
- Product, sprint, QA, release and resume templates.
- Five portable skills and four role prompts; not autonomous runtimes.
- Publishing-first STOS example without private production data.
- Automated CLI/library tests and GitHub Actions CI configuration.

## Proposed, not implemented
- Authenticated Jira reconciliation adapter with conflict protection.
- Cryptographically trusted CI evidence ingestion and reviewer identity binding.
- Schema migrations, transition history and multi-release selection.
- Hosted project dashboard and additional agent-runtime adapters.

Do not market these proposals as available features. Prioritize verified adoption of one STOS publishing slice before increasing agent count or adding billing/automation scope. No launch dates are committed without capacity and owner agreement.
