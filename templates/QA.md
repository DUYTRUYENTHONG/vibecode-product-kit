Test the real user journey and recovery, not only an API or screenshot. Include access boundaries, restart persistence, concurrent edits, failed network, long content, keyboard and reduced motion when applicable. Do not use production credentials or personal data in public evidence.

## Findings
Severity, reproduction, expected/actual result, responsible owner, retest scope. Do not present skipped tests as passed. A new candidate invalidates evidence unless explicitly revalidated for that candidate.
